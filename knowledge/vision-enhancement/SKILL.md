# 物品识别增强 Skill

## 元信息
- **名称**: 物品识别增强
- **版本**: 1.0.0
- **适用场景**: 断舍离 Agent 图片识别补充

## 触发条件
当以下情况发生时自动触发本 Skill：
- 用户上传待整理区域的图片
- 断舍离 Agent 检测到图片识别结果中物品数量低于预期
- 用户反馈识别结果不完整，特别是指出小件物品（如梳子、文具、化妆品等）未被识别

## 核心功能

### 1. 图片二次分析
对原始图片进行多层次、多尺度的分析：

- **全局扫描**: 先整体分析图片，识别场景类型（卧室、书房、浴室、厨房等）
- **分区扫描**: 将图片划分为 3x3 或 4x4 网格，逐一分析每个区域
- **局部放大**: 对可疑区域进行局部放大分析，特别关注边缘和角落

### 2. 小物件专项识别
针对容易被忽略的小件物品进行专项检测：

- **个人护理类**: 梳子、发夹、皮筋、指甲剪、棉签、化妆刷等
- **文具类**: 笔、橡皮、回形针、便签、订书机等
- **配件类**: 钥匙、眼镜、耳机、充电线、U盘等
- **厨房小物**: 调料瓶、开瓶器、量勺、削皮器等
- **其他小件**: 打火机、小工具、装饰品、药物等

### 3. 多模态推理
结合物品的空间关系和上下文信息进行推理：

- **位置关系推理**: 物品是否在合理位置？（如梳子在卫生间区域）
- **配套关系推理**: 识别到的物品是否暗示有配套物品存在？（如看到梳妆镜则推断可能有梳子）
- **遮挡推断**: 根据可见物品推断被遮挡区域可能存在的物品

### 4. 交互式确认
生成增强识别结果后，主动与用户交互确认：

- 列出新增识别到的物品，请求用户确认
- 对置信度较低的小物件以提问方式向用户核实
- 询问是否有遗漏的特殊物品

## 工作流程

```
用户上传图片
    ↓
调用基础图像识别 API（原有流程）
    ↓
判断识别结果是否完整
    ↓
【触发本 Skill】
    ↓
执行多尺度图像分析
    ↓
执行小物件专项检测
    ↓
执行多模态推理补全
    ↓
合并识别结果
    ↓
生成交互式确认问题
    ↓
用户确认/补充
    ↓
输出最终增强识别结果
    ↓
继续断舍离计划生成
```

## 与断舍离 Agent 的集成

### 输入接口
- `image_url`: 图片 URL 或 base64
- `original_result`: 原始识别结果（可选）
- `user_feedback`: 用户反馈的遗漏物品（可选）

### 输出接口
- `enhanced_items`: 增强后的物品列表
- `confidence_level`: 整体置信度
- `pending_questions`: 需要用户确认的问题列表
- `suggestions`: 改进建议

## 实现建议

### 技术方案
1. **使用多模型组合**:
   - Grounding DINO / OWLv2: 开放词汇目标检测
   - CLIP: 零样本分类验证
   - SAM: 分割辅助定位小物件

2. **图像预处理**:
   - 超分辨率增强（Real-ESRGAN）
   - 对比度/亮度自适应调整
   - 边缘增强滤波

3. **提示词策略**:
   - 针对不同场景使用不同的检测提示词集合
   - 使用 Chain-of-Thought 提示词引导逐步推理

### 降级方案
当自动识别结果仍不理想时：
- 主动请求用户提供更多角度照片
- 生成结构化问卷帮助用户自查物品清单
- 提供物品分类模板供用户勾选

## 使用示例

### 示例 1：梳妆台照片
**用户输入**: 上传梳妆台照片，原始识别只识别出「镜子」「粉底液」「手机」

**Skill 增强结果**:
- 新增识别：木梳（梳妆台左前侧）、黑色发圈（镜子右下角）、睫毛夹（粉底液旁边）
- 待确认：是否有散粉？（检测到疑似粉扑）
- 建议：抽屉内可能有更多物品，建议打开拍照

### 示例 2：书桌照片
**用户输入**: 上传书桌照片，原始识别只识别出「电脑」「水杯」「书籍」

**Skill 增强结果**:
- 新增识别：签字笔（笔筒内）、回形针（桌面右上角）、便签纸（显示器底座旁）
- 待确认：抽屉拉手可见，请确认是否有需要整理的物品在抽屉内

## 注意事项

1. **隐私保护**: 处理图片时应注意去标识化，不存储用户原始图片
2. **置信度阈值**: 对新增识别的小物件设定合理置信度阈值（建议 0.7），低于阈值的进入待确认列表
3. **用户体验**: 避免过多确认问题（建议不超过 5 个），将低优先级问题整合为清单供用户自查
4. **持续学习**: 记录用户确认的数据，持续优化识别准确率

## 实现状态（v1 落地记录）

本 skill v1 已接入应用，落地取舍如下（详见 server/vision.py）：

- ✅ 二段式识别：第一遍全局扫描（增强提示词：逐一识别、不合并）+ 第二遍小物件专项补扫（带第一遍结果，只报遗漏）
- ✅ 小物件五类清单 → 第二段提示词与 category 枚举（新增 care/stationery/accessory/tool）
- ✅ 交互式确认（轻量版）：仅第二遍新发现的物品进 `suspected` 待确认列表 → Agent 摘要标注 + 系统提示词要求先向用户确认再入库 + 前端虚线标签
- ⛔ 模型自报 confidence/location 字段：不采用（VLM 自报数字未校准，幻觉风险）；以「仅第二遍发现」作为低置信的行为代理
- ⛔ 多模型组合（DINO/CLIP/SAM）与超分：需模型服务基建，留待 v2
- ⛔ 网格分区裁切 ×9 调用：成本过高，两段提示词已覆盖主要收益
- ⚠️ 隐私条款与应用现有「照片存本地 server/data/photos/」设计冲突，维持现状（README 已声明）
- 开关：环境变量 `VISION_TWO_PASS=0` 关闭第二遍（本地 Ollama 慢速场景）
