# 断舍离 速查决策表

## 判断物品去留

| 情形 | 判断 | 依据 |
|---|---|---|
| 已损坏/被弄脏/被抛到脑后 | 直接清（集体面试） | 第一层筛子：怎么看都是垃圾废品 |
| "还能用"但犹豫 | 问：还在"心的保质期"内吗？对现在的自己仍"美味"吗？ | 有效性≠必要性 |
| 别人送的/大牌/贵 | 只问"我想不想用"，不问"还能不能用" | 他人轴/物质轴=焦点错位 |
| 一年未用、将来"总会用上" | 警惕忧虑未来型；从关联度而非频率判断 | 时间轴必须是"现在" |
| 有情感故事但非喜爱 | 若附着的是负面情感（贵/可惜/买不到），关系已非良性 | 执念心第二型 |
| 同类≥3件 | 保留最佳1-2件 | 重复囤积信号 |

## 收纳物量红线

| 空间类型 | 上限 | 例 |
|---|---|---|
| 看不见（关门即隐） | **7成** | 衣柜、壁橱、抽屉、鞋柜、冰箱内部 |
| 看得见（玻璃门/开放） | **5成** | 餐具柜、书架 |
| 展示性（水平面） | **1成** | 玄关台面、桌面（只放一束花） |

## 入手新物

> **先出后进**：处理一个 → 才收纳一个。顺序反了总量必超标。

- 犹豫要不要买？→ 有犹豫就不买（背水一战法自然筛选）
- 想送人/拍卖旧物换钱？→ 除非有非常大决心，再利用的麻烦正是杂物堆积的原因之一；与物品的缘分已尽就痛快放手

## 流程顺序（勿颠倒）

```
观念3步 → 拿出俯瞰 → 三层筛子 → 收纳(三分法+7·5·1) → 清扫擦拭
```

- 先买收纳用品再整理 = 本末倒置
- 先扫地后取舍 = 给废品掸灰
- 收纳出发点是"如何才能不做收纳"

## 从哪里开始

| 状态 | 起点区 |
|---|---|
| 完全新手 | 鞋柜、冰箱（判断简单、执念少） |
| 有心无力/疲惫 | 厨房出口（水池/排水管/垃圾桶）、3B |
| 想快速见效激励 | 餐具柜（看得见的美化最能激发动力） |
| 忌 | 书籍、情结物、大块头家具（执念最强） |

## 家人东西碍眼时

1. 不碰、不扔、不替他决定
2. 展示自己享受断舍离的样子（北风与太阳）
3. 话术：「你挑挑自己喜欢的吧」≠「快扔掉这垃圾」
4. 进阶：主动帮忙"美观展示"其心爱之物 + 一年后复查约定

## 无法继续时的自检

| 症状 | 药方 |
|---|---|
| "提不起劲儿" | 缩小单位到一双筷子；加分法表扬自己 |
| "越收拾越乱" | 检查是否跳过了取舍直接收纳 |
| "扔了会发愁" | 设想发愁的只是现在的自己；先扔再发愁（增压训练） |
| 自责"废柴" | 局面不全是你的错：消费社会+旧价值观+空间估测不足 |
| 对家人愤怒 | 检查自己是否期待过高；先彻底整理好自己的东西 |

## 关键阈值

- 居所内容物 **80% 是忘却物**（陌生的大叔）——别高估自己物品的使用率
- 观察期类推：犹豫物品给观察期，但时间轴始终拉回"现在"再判断
- 每天做**天单位**清零 → 年底无大扫除
- 提前 **5分钟** = 日程的"间"

## 一句话原则

> 舍得难舍的，获得应得的。有舍，便有得。
> 断舍离即"出"之美学——先吐后吸，一出一进。
