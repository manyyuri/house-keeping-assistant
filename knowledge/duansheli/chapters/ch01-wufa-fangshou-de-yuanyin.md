# 第1章 你之所以无法放手的原因

## Core Idea
无法收拾不是因为懒或能力不足，而是"物质轴"思维（以物品能不能用为判断基准）+ 三类心理倾向 + 消费社会的结构性压力共同作用的结果。断舍离的入口是把判断基准从"物品"切换到"空间"和"现在的自己"。

## Frameworks Introduced
- **水槽·鲇鱼比喻**
  - When to use: 理解家庭杂物堆积的动态机制时
  - How: 家 = 水槽。"断"是进水阀（松动则杂物涌入），"舍"是出水阀（"太浪费了""真麻烦""总会用上的"把它锈死）。进出阀同时故障，水槽就变成死水淤泥地。修理顺序：先开出水阀（舍），进水阀自然收紧。
- **囤货三大原因**
  - When to use: 分析自己为什么东西多时
  - How: ① 消费社会洪水般的物量（物理原因）② 对舒适生活所需物品量估测不足（技术原因）③ 上个时代的价值观——"太可惜了""不能浪费"（观念原因）。注意第三条最难察觉：它是继承来的，不是自己选的。
- **物质轴 vs 空间轴**
  - When to use: 对任何一件物品做去留判断时
  - How: 物质轴问"这个东西还能不能用？"→ 还能用就留。空间轴问"为确保空间干净整洁，物品量是否已缩减到最适合的量？"→ 先保证空间，再谈物品。断舍离注重的不是物品，而是空间。
- **无法放手的三类人**
  - When to use: 诊断自己（或指导他人）的囤积倾向时
  - How:
    - 逃避现实型：工作忙不待在家，家里乱→更不想待，恶性循环。但一旦开始整理，反而干净利落不犹豫。
    - 执着过往型：珍藏旧相册、信件、纪念品，口头禅"太可惜了"，不愿直面现在。
    - 忧虑未来型：人数最多。"没有它会发愁"，不停为未来储备物资（囤纸巾类）。
    - 共通点：对"现在"的时间意识淡薄——意识徘徊在过去或未来，唯独不在当下。三种倾向每人内部都有，只是占比不同。
- **"舍"与"弃"的不同**
  - When to use: 决定如何处理一件物品时
  - How: "弃"= 弃置不管（家里被弃置的废品和外面的垃圾本质相同，只不过一个在里面一个在外面）。"舍"= 布施之"施"，让物品在别处起作用（送人、捐赠、规范回收）。断舍离要求的是"舍"，不是"弃"。
- **三种自由**
  - When to use: 因他人眼光（家人说"太可惜"）而无法行动时
  - How: 人本来就拥有放手的自由、保留的自由、取舍选择的自由。"吃不吃饭我做主，穿不穿我做主"——自己的东西自己做主，不必为物品留情，不必在意任何人眼光。

## Key Concepts
- **执念的黏着剂**：物品自带看不见的黏着剂，看见时执念就在心里生根。收集精美包装盒是典型条件反射。
- **冷宫比喻**：塞满不穿衣服的衣柜 = 皇帝不会驾临的冷宫，涌出惰性的洪流，人也感染惰性。
- **家里家外反差**：职场精明能干的高知女性 + 家里杂物贫民窟，反差越大自责越深。
- **收纳率200%**：抽屉塞到超出容量，是"塞东西"阶段而非"囤积"阶段。

## Mental Models
- Think of 杂物堆积 as 便秘：只进不出，毒素累积，亚健康→疾病，但警戒线在哪看不出来。
- Use "把物品占比换算成房租" when 犹豫是否保留大件：废品占地几年的累计房租远超其本身价值。

## Anti-patterns
- **用"收纳术"解决杂物过多**：把过多物件密密实实塞满生活，本质是在"浪费、过剩、惰性"中喘不过气。收纳式思维治标不治本。
- **把"不会收拾"当能力问题**：女性尤其容易自我定义为"不会整理的废柴女"，双重受害（环境之害+自责之害）。
- **以"还能用"留物**：哲学家语——人们习惯思考"有效性"，却忽略作为其前提的"必要性"。

## Worked Example
**体验谈2（洋子）**：30多岁职场白领，外表光鲜，家里资料遍地、搬家纸箱未拆封落灰、满架占卜灵修书。交往对象都是已婚人士——住处和恋爱同样"不可告人"。参加断舍离讨论会后明白"扔掉不需要的杂物、建立舒适空间，才可能改变人生"。用三个月处理掉杂物废品，随后敢说出"有空来我家玩"，遇见同龄干净利落的伴侣并结婚。
→ 应用要点：居住空间是内心状态的"相"，清理外物与改善际遇同步发生。

## Key Takeaways
1. 判断基准从"物品能不能用"（物质轴）切换到"空间需要什么"（空间轴），是断舍离的第一步。
2. "太可惜了"多数时候不是珍惜，而是回避处理杂物的免罪牌。
3. 先诊断自己的三型倾向（逃避现实/执着过往/忧虑未来），对症下药。
4. 处理物品用"舍"（流转出去）而非"弃"（弃置不管）。
5. 东西多不全是你的错——消费社会设计让你买东西，上个时代的观念让你不敢扔。
