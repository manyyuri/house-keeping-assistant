# 断舍离 (Danshari) — 山下英子

> 人生を変える断捨離，贾耀平译。全书约250页，核心是"出"之美学：通过物品取舍恢复空间与人生的新陈代谢。

## 何时使用本 Skill

- 评估物品去留、设计收纳方案、制定整理计划时
- 构建整理类应用（如家务 Agent）需要评分/建议规则时
- 用户提及"断舍离""极简"" decluttering""舍不得扔"等场景时

## 核心决策速查（最常用）

1. **三层筛子**：垃圾废品直接清 → 自我轴×时间轴（我想不想用，而非还能不能用）→ 必要·合适·愉快终审
2. **7·5·1 物量红线**：看不见的空间7成、看得见5成、展示性1成
3. **1 out 1 in**：先出后进，总量守恒
4. **入手纠结**：有犹豫就不买；设想"扔了会发愁"的只是现在的自己
5. **家人之物**：不碰不扔，展示享受的姿态感染（北风与太阳）

详见 `cheatsheet.md`（决策表全集）。

## 完整流程（应用时的骨架）

```
观念3步：认识现状 → 停止自我否定 → 描绘家的具体构想
杂物5步：拿出俯瞰 → 清垃圾废品 → 自我轴时间轴关联度 → 必要合适愉快 → （最适化后才）收纳
收纳5指南：三分法 | 7·5·1法 | 1 out 1 in法 | one touch法 | 自立自由自在法
```

## 整合应用笔记

构建整理类工具（如断舍离 Agent）时：
- 评分维度建议直接采用：**关联度（自我轴×时间轴）+ 必要/合适/愉快 + 7·5·1 空间占比**
- 初学者路线：鞋柜/冰箱起步 → 厨房出口 → 餐具柜激励 → 最后才碰书籍/情结物
- 90 天类犹豫物品机制与本书"心的保质期""先扔再发愁"思想兼容
- 忌讳：替用户对家人之物做决定；跳过取舍直接给收纳方案
